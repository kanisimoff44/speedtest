# Запуск

```bash
python3 speedtest.py https://speed.cloudflare.com/__down?bytes=10000000
```

# Как работает

- Принимает URL позиционным аргументом; опционально -n (число запросов, по умолчанию 10) и -t (таймаут).
- Делает запросы строго последовательно, каждый читает тело ответа до конца и замеряет время через time.perf_counter().
- Шлёт Cache-Control: no-cache, чтобы не получить ответ из кэша.
- Упавшие запросы (таймаут, 429 и т.п.) не ломают прогон.
- В конце печатает среднее время запроса, суммарный объём и скорость в МБ/с (суммарные байты / суммарное время).
